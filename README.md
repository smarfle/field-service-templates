# Free Field Service Templates

Free Google Sheets and Google Docs templates for small service businesses, such as cleaning, pest control, HVAC, plumbing, lawn care and handyman companies. Each one is a working file you can copy into your own Google Drive and use right away, with no software to install. Most include a filled sample so you can see how a finished one looks.

Made by [Smarfle](https://www.smarfle.com), software for home and field service businesses.

Each template has its own page with what is inside, how to fill it in and starter files you can download.

## How to use a template

1. Open the template from the tables below.
2. In Google Sheets or Google Docs, choose **File, Make a copy**.
3. Rename your copy and fill it in. The original stays as it is for the next person.

Every Google Sheet also has a download link for Excel inside it.
