# How to use this template
1. Make a private copy. Enter the project, customer, contractor, original contract reference, change number and date. Use a separate change number for each approval.  
2. Describe what is added, removed or revised and why. Identify affected drawings, rooms, equipment or service visits. Attach detail if the description needs more space.  
3. Type additions as positive amounts and credits as negative amounts. Add labor, materials, other costs and any applicable tax to get the net change. This document does not calculate totals automatically.  
4. Add the original contract amount and all previously approved changes to get the contract total before this change. Add the net change for the new contract total. Do not count this change twice or treat the new total as the unpaid balance.  
5. State whether the time change uses calendar days or business days and write the new completion date. Check that the number of days and both dates agree. Record dependencies and any deposit or payment adjustment.  
6. The sample is $1,200 original plus $100 earlier changes plus $220 for this change, giving $1,520. It adds one calendar day. The zero tax assumption is fictional; check the tax treatment for your work.  
7. Have local counsel review changes to contract or consumer terms when needed. Remove the Sample and notes from the approval copy. Both parties sign before the changed work begins and keep the same version with the original contract. The Word and PDF links download the whole template, not just the approval page.
