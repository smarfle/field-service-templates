# How to use this template
1. Make a private copy, replace the bracketed fields and assign a unique work order number. Put the business name and a reachable customer phone on the form.  
2. Record the scheduled date, arrival window, service address and technician. Describe the authorized work before the technician starts. Keep entry codes and other sensitive access details in a private channel.  
3. Print only the work order page or use the private digital copy in the field. Mark a task box with a pen on paper, or change [ ] to [x] in the document. The boxes are printable text, not automated workflow controls.  
4. Write the actual materials and quantities used. Record labor as decimal hours, such as 1.50 for one hour and 30 minutes. If breaks or multiple visits affect time, note them or attach a time record.  
5. Use Before work to document the starting condition and any existing damage. Use After work for the result and tests. Put unresolved issues, customer exceptions and follow-up in the completion notes.  
6. Ask the customer to review the record and sign. If unavailable or declining to sign, note that fact rather than signing for them. This is a job record, not an invoice or permission to add charges beyond the agreed scope.  
7. Delete the Sample and usage notes from the customer version. The top Word and PDF links download the full template. To send only the form, print the relevant page to PDF. Check page fit after adding longer notes, and attach another page rather than shrinking the text.
