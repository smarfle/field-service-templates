# Free Expense Report Template

For employees who pay out of pocket for parts or fuel and need a clean report the owner can approve and pay back.

**[Open the template](https://docs.google.com/spreadsheets/d/1lTV8eSFgED0NmTx5VXtjC4zkFvNXFpgReGaPpGf8Wts/edit)** &middot; **[Make a copy](https://docs.google.com/spreadsheets/d/1lTV8eSFgED0NmTx5VXtjC4zkFvNXFpgReGaPpGf8Wts/copy)** &middot; Google Sheet, free, no sign-up

## What is inside

| Tab | What it holds |
|---|---|
| Dashboard | Totals and views built from Reports, Expenses and Employees, no typing needed. |
| Expense Report | Totals and views built from Reports, Expenses and Employees, no typing needed. |
| Reports | Columns Report number, Employee ID, Period start, Period end, Business purpose, Advance received, Mileage rate, Mileage rate override (optional), Approval status and 2 more. |
| Expenses | Columns Line ID, Report number, Date, Type, Vendor or trip route, Category, Job or client, Payment method, Cash amount and 3 more. |
| Employees | Columns Employee ID, Name, Email and Role. |
| Settings | Your own dropdown lists (fuel and cash), so the choices match how you work. |

## How to fill it in

1. Add employees on Employees.
2. Start a report on Reports with the period, the purpose and any advance.
3. Add each cost or trip on Expenses with a receipt link or the miles.
4. Print the Expense Report tab for approval, then record the paid date.

## A tip from the field

Mileage lines use the rate set on the report, so set it once per period instead of once per trip.
