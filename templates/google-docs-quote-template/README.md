# Free Google Docs Quote Template

For fixed-price work with a clearly defined scope, where the customer wants one number and a plain list of what it covers.

**[Open the template](https://docs.google.com/document/d/1vam2-pzKL8TUhzVRbh5DbbhmA7_2E82_a-sM3SzcYRg/edit)** &middot; **[Make a copy](https://docs.google.com/document/d/1vam2-pzKL8TUhzVRbh5DbbhmA7_2E82_a-sM3SzcYRg/copy)** &middot; Google Doc, free, no sign-up

## What is inside

- Business, Customer and service address
- Quote #, Date, Valid until
- Fixed scope
- Description, Qty, Rate in USD, Amount in USD
- Quote totals in USD
- Fixed-price statement
- Exclusions and assumptions
- Schedule and payment
- Other terms and attachments
- Customer acceptance, Date

A filled sample shows how a finished copy reads.

## How to fill it in

1. Describe the scope item by item in plain words.
2. List the price of each part and the total.
3. State what is excluded and how long the price holds.
4. Add the acceptance line and send it as a PDF.

## A tip from the field

Write exclusions as plainly as the scope. Many disputes start with work the customer assumed was included.
