# Free Google Sheets Estimate Template

For trades that price from a list, per room, per visit or per square foot, and want consistent printable estimates with deposit and tax worked out.

**[Open the template](https://docs.google.com/spreadsheets/d/1EQjLhVth5w5m9E6cuFsitsGtgs8EkR6IP6uMzn0vM-s/edit)** &middot; **[Make a copy](https://docs.google.com/spreadsheets/d/1EQjLhVth5w5m9E6cuFsitsGtgs8EkR6IP6uMzn0vM-s/copy)** &middot; Google Sheet, free, no sign-up

## What is inside

| Tab | What it holds |
|---|---|
| Dashboard | Totals and views built from Estimates, Line Items and Price List, no typing needed. |
| Estimate | Totals and views built from Estimates, Line Items and Price List, no typing needed. |
| Estimates | Columns Estimate number, Date, Customer name, Phone, Email, Job address, Status, Valid until override (optional), Discount type and 5 more. |
| Line Items | Columns Line ID, Estimate number, Service, Quantity, Description override (optional), Unit override (optional), Rate override (optional), Taxable override (optional) and Internal line note. |
| Price List | Columns Service, Description, Unit, Rate and Taxable. |
| Settings | Your own dropdown lists (unit, status and discount type), so the choices match how you work. |

## How to fill it in

1. Fill Price List with your services, units, rates and what is taxable.
2. Start an estimate on Estimates with the customer and job address.
3. Add lines on Line Items by picking services and quantities.
4. Choose the estimate number on the Estimate tab, then print it or save it as PDF.

## A tip from the field

Use the Follow-up date column. Plenty of estimates that go quiet only need one friendly reminder.
