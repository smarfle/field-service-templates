# Free Google Sheets Scheduling Template

For crew leads who build next week on a whiteboard and want to catch time off, availability and overtime before the week starts.

**[Open the template](https://docs.google.com/spreadsheets/d/18vWRBg8UmkzsWI1dffrlGflMQmpsX-BdILsyFSpeSiU/edit)** &middot; **[Make a copy](https://docs.google.com/spreadsheets/d/18vWRBg8UmkzsWI1dffrlGflMQmpsX-BdILsyFSpeSiU/copy)** &middot; Google Sheet, free, no sign-up

## What is inside

| Tab | What it holds |
|---|---|
| Dashboard | Totals and views built from Shifts, Employees, Availability and Time Off, no typing needed. |
| Weekly Schedule | Totals and views built from Shifts, Employees, Availability and Time Off, no typing needed. |
| Shifts | Columns Shift ID, Date, Employee ID (blank = open), Start, End, Unpaid break minutes, Role or crew, Location and Notes. |
| Employees | Columns Employee ID, Name, Role, Phone, Hourly rate (optional), Max hours per week, Active and Effective weekly limit. |
| Availability | Columns Employee ID, Weekday, Available from, Available to, Unavailable, Availability key, From minute, To minute and Weekday number. |
| Time Off | Columns Employee ID, Start date, End date, Type, Approved and Notes. |
| Settings | Your own dropdown lists (time-off type and weekday), so the choices match how you work. |

## How to fill it in

1. Add employees with max hours per week, then their weekly availability.
2. Enter approved time off.
3. Create shifts on Shifts, leaving the employee blank for an open shift.
4. Review Weekly Schedule for flags, hours and known cost per person.

## A tip from the field

The Rest alert checks the hours between one shift's end and the next start, handy when a late job is followed by an early one.
