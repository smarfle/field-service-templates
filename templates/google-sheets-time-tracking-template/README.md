# Free Google Sheets Time Tracking Template

For crews that bill some jobs by the hour and need to see, per job and per client, how many hours were worked, which were billable and what the labor really cost.

**[Open the template](https://docs.google.com/spreadsheets/d/17HZlts1YZP3suYRV5FIBdVISq1J67U5uPD3TNZoKdGs/edit)** &middot; **[Make a copy](https://docs.google.com/spreadsheets/d/17HZlts1YZP3suYRV5FIBdVISq1J67U5uPD3TNZoKdGs/copy)** &middot; Google Sheet, free, no sign-up

## What is inside

| Tab | What it holds |
|---|---|
| Dashboard | Totals and views built from Time Entries, Employees, Clients and Jobs, no typing needed. |
| Time Entries | Columns Entry ID, Employee ID, Employee, Job ID, Client, Service, Start date, Start time, End date (optional) and 16 more. |
| Employees | Columns Employee ID, Name, Role, Default billing rate (USD/hr), Default cost rate (USD/hr), Status, Email and Notes. |
| Clients | Columns Client ID, Customer / company, Customer type, Service city, Email, Phone and Notes. |
| Jobs | Columns Job ID, Client ID, Client, Service, Job description, Default billing rate (USD/hr), Status and Notes. |
| Settings | Your own dropdown lists (service), so the choices match how you work. |

## How to fill it in

1. Add each person on Employees with a default billing rate and a cost rate.
2. Add clients and jobs, then log each shift on Time Entries with start, end and break minutes.
3. Mark each entry billable or not, and set approval once a manager has checked it.
4. Read Dashboard for approved hours, billable amount and labor cost per person.

## A tip from the field

Shifts that run past midnight work fine, just add the end date. The Overlap alert column flags two entries for one person at the same time.
