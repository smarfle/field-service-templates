# Free Google Sheets Timesheet Template

For crews that record hours per person per day and need a weekly timesheet with regular and overtime hours that can be printed and signed.

**[Open the template](https://docs.google.com/spreadsheets/d/1IDhS7Le_3dYOM_Tv5ZMr82pvtjgwpOsjL_EMU0Lh9D0/edit)** &middot; **[Make a copy](https://docs.google.com/spreadsheets/d/1IDhS7Le_3dYOM_Tv5ZMr82pvtjgwpOsjL_EMU0Lh9D0/copy)** &middot; Google Sheet, free, no sign-up

## What is inside

| Tab | What it holds |
|---|---|
| Weeks | Totals and views built from Time Entries and Employees, no typing needed. |
| Timesheet | Totals and views built from Time Entries and Employees, no typing needed. |
| Time Entries | Columns Entry ID, Start date, Employee ID, Job or client, Start time, End time, Unpaid break minutes, Approval status and Notes. |
| Employees | Columns Employee ID, Name, Role, Hourly rate (optional) and Active. |
| Settings | Your own dropdown lists, so the choices match how you work. |

## How to fill it in

1. Add employees, with an hourly rate if you want labor cost.
2. Log each work period on Time Entries with start, end and unpaid break.
3. Mark entries approved after you review them.
4. Open Timesheet for one person's week and Weeks for the whole team.

## A tip from the field

The Overlap alert flags entries that cross each other, which usually means a mistyped time.
