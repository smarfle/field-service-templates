# Free Google Sheets Work Order Template

For technicians and office staff who want a printable work order with labor, materials, priority and a signature line, plus a log of every order.

**[Open the template](https://docs.google.com/spreadsheets/d/1lTf6mBdZEbFj52zcHBz-uuQaZai4240lI3nvdLEk_q4/edit)** &middot; **[Make a copy](https://docs.google.com/spreadsheets/d/1lTf6mBdZEbFj52zcHBz-uuQaZai4240lI3nvdLEk_q4/copy)** &middot; Google Sheet, free, no sign-up

## What is inside

| Tab | What it holds |
|---|---|
| Dashboard | Totals and views built from Work Orders, Materials and Price List, no typing needed. |
| Work Order | Totals and views built from Work Orders, Materials and Price List, no typing needed. |
| Work Orders | Columns Work order number, Created date, Customer name, Phone, Service address, Requested work, Technician ID, Scheduled date, Arrival window and 10 more. |
| Materials | Columns Line ID, Work order number, Item, Quantity, Unit override (optional), Unit price override (optional), Taxable override (optional), Description override (optional) and Notes. |
| Price List | Columns Item, Description, Unit, Unit price, Taxable and Kind. |
| Settings | Your own dropdown lists (unit, technician id, technician name, status and priority), so the choices match how you work. |

## How to fill it in

1. Fill Price List with parts and labor items.
2. Create the order on Work Orders with the requested work, technician and arrival window.
3. Add materials on Materials as they are used.
4. Choose the order number on Work Order and print it for the job or the customer.

## A tip from the field

Record labor hours and materials the same day. Orders filled in from memory at the end of the week miss parts.
